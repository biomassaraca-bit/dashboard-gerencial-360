DASHBOARD GERENCIAL 360 — PWA

Publicar os arquivos desta pasta na raiz de um repositório GitHub Pages público dedicado, por exemplo dashboard-gerencial-360.
Settings > Pages > Deploy from a branch > main / root.
Endereço resultante (se este for o nome escolhido): https://biomassaraca-bit.github.io/dashboard-gerencial-360/
A URL só existirá após publicação e ativação do GitHub Pages.
Android: Chrome > menu > Adicionar à tela inicial / Instalar aplicativo.
iPhone: Safari > Compartilhar > Adicionar à Tela de Início.

A chave publishable está pré-configurada; login continua obrigatório. O login pode ser lembrado no aparelho via sessão do Supabase; não há senha fixa. Dados requerem internet e permissões RLS apropriadas. Atualização automática a cada 2 minutos enquanto a página estiver aberta.
